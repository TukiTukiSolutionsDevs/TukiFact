# OpenAPI contract

`tukifact-api-v1.json` is generated by `dotnet build` of `src/TukiFact.Api` (Microsoft.Extensions.ApiDescription.Server) and is committed on purpose so API surface changes show up in review.
Do not edit it by hand: the next build overwrites it.
CI fails when the committed file drifts from the build output; run `dotnet build TukiFact.slnx` and commit the result.
